Dentro de .streamlit criar arquivo secrets.toml com conteúdo:

SUPABASE_URL='<PATH: 1>'
SUPABASE_KEY='<PATH: 2>'

PATH 1:
    - Connection button
    - Framework [Python - Flask]
    - .env -> SUPABASE_UR

PATH 2:
    - Project Settings
    - API Keys [Menu]
    - Secret keys [default]
